# 变化点分类库(Layer 0)

8 维度 × 3 信号。Phase A 逐维度扫描;每个信号附启发问题(源自 Change Cases)。评分口径:
可能性 H=已有明确迹象/M=行业常见/L=偶发;影响面 H=需改核心流程或数据结构/M=需改多个模块/L=局部改动。

## 1. 业务规则与流程
- **B1 定价/费率/折扣规则调整** — 启发:规则未来会参数化吗?会按客户分层吗?
- **B2 审批流/状态机变化** — 启发:会新增状态或跳过环节吗?会按金额分级审批吗?
- **B3 新业务对象类型** — 启发:会出现新的单据/商品/服务类型吗?

## 2. 集成与依赖
- **I1 第三方服务替换** — 启发:供应商会被换掉吗(价格/稳定性/合规原因)?核心逻辑是否泄漏了 SDK 细节?
- **I2 新增同类外部服务** — 启发:会并行接入第二家吗(多渠道/灾备)?
- **I3 外部协议或接口版本变化** — 启发:上游有版本升级公告吗?字段会增减吗?

## 3. 数据演进
- **D1 schema 变更** — 启发:核心实体字段会增减吗?历史数据要迁移吗?
- **D2 存储引擎/数据源更换** — 启发:量级或成本会逼迫换存储吗?
- **D3 数据量级增长** — 启发:10 倍数据后现查询/分页/归档策略还成立吗?

## 4. 接口与契约
- **C1 API 版本升级/新客户端形态** — 启发:会出现小程序/开放平台/第三方调用吗?旧契约要兼容多久?
- **C2 同步转异步/批量** — 启发:耗时会随量级恶化到必须异步化吗?
- **C3 开放 API 给第三方** — 启发:合作伙伴会直接调我们的能力吗?鉴权与限流预留了吗?

## 5. 规模与性能
- **S1 流量/并发量级增长** — 启发:促销峰值会到多少 QPS?现在几倍余量?
- **S2 时延要求收紧** — 启发:有 SLA 承诺或体验目标吗?
- **S3 批量处理能力** — 启发:会出现批量导入/批量结算诉求吗?

## 6. 部署与配置
- **P1 多环境/多租户/SaaS 化/私有化** — 启发:同一代码会部署到不同形态吗?数据要按租户隔离吗?
- **P2 feature flag 与灰度** — 启发:新能力要小流量验证吗?出问题要秒级回滚吗?
- **P3 配置项变化** — 启发:阈值/开关/端点会按环境或运营调整吗?

## 7. 用户与场景
- **U1 国际化/多语言/多时区** — 启发:会出海或服务多区域吗?
- **U2 新用户角色/权限模型变化** — 启发:会出现新角色(审核员/代理商)吗?
- **U3 新通知渠道/交互形态** — 启发:通知会从邮件扩到短信/推送/webhook 吗?

## 8. 技术栈与合规
- **T1 框架大版本升级/运行时更换** — 启发:当前框架 EOL 时间?升级窗口?
- **T2 法规合规** — 启发:数据留存/审计/隐私(如等保、GDPR 类)要求会变吗?
- **T3 安全要求变化** — 启发:加密算法/认证方式会被要求更换吗?

## 使用规则
1. 扫描时逐维度过一遍,宁多记后删,不凭感觉跳过维度
2. 每条变化点必须给依据;需求原文 > 领域常识 > `[推断]`
3. 命中但库内无对应信号的 → 记入登记表"新信号登记"区(Layer 2)
